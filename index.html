🌐 Wialon (lista de veículos + KM)

Crie em Wialon → Conta → Tokens de acesso. Permissão: Acesso Online. O token busca a lista de veículos e o odômetro em tempo real.

🔑 FleetRun API (envio automático)

FleetRun → Menu Usuário → API Tokens → Criar token com permissão Serviços e Abastecimentos.

🤖 Claude IA (leitura de fotos)

Obtenha em console.anthropic.com. A IA lê as fotos das notas fiscais e extrai todos os dados automaticamente.

🔄 Monitor Automático (MD-e)

URL gerada após o deploy das Firebase Functions. Habilita o monitor automático de NF-e via MD-e (Focus NFe).
